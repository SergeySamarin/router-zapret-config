# router-zapret-config

Конфигурация для обхода блокировок/замедления YouTube и Discord на домашнем роутере
(TP-Link EC220-G5 v2, прошивка Padavan) через **nfqws** (часть проекта
[bol-van/zapret](https://github.com/bol-van/zapret)), без Entware/USB.

## Как это работает

Роутер при каждом поднятии интернета (WAN) или пересборке правил firewall
(например, при переключении VPN-клиента) автоматически:

1. Скачивает бинарник `nfqws` под архитектуру роутера (mipsel), если его ещё нет.
2. Скачивает свежие списки доменов из папки `lists/` этого репозитория.
3. Добавляет правила `iptables`, заворачивающие трафик 443 порта в очередь NFQUEUE.
4. Запускает `nfqws`, если он ещё не запущен.

Всё хранится во временной папке `/tmp` на роутере (сбрасывается при перезагрузке),
поэтому автозапуск через хуки ниже — обязателен.

## Файлы

- `setup.sh` — основной скрипт установки/переустановки. Идемпотентный:
  безопасно запускать повторно, не создаёт дублей.
- `lists/list-general.txt` — домены Discord и связанных сервисов.
- `lists/list-google.txt` — домены YouTube/Google, включая домены авторизации
  Google (нужны для работы YouTube-приложения на Smart TV).

## Настройка на роутере (Padavan)

`Advanced Settings → Customization → Scripts`, вставить в оба поля:

**Run After WAN Up/Down Events** и **Run After Firewall Rules Restarted**:

```sh
wget -q https://raw.githubusercontent.com/SergeySamarin/router-zapret-config/main/setup.sh -O /tmp/setup.sh
sh /tmp/setup.sh
```

## Как обновить список доменов

Просто отредактировать нужный файл в папке `lists/` прямо на GitHub
(через веб-интерфейс, кнопка карандаша) и закоммитить. Новая версия
подтянется автоматически при следующем срабатывании хуков (перезагрузка
роутера, переподключение WAN, изменение правил firewall) — либо запустить
вручную через консоль роутера:

```sh
sh /tmp/setup.sh
```

## Проверка статуса на роутере

```sh
ps | grep nfqws
iptables -L FORWARD -n | grep NFQUEUE
```

## Известные ограничения

- Требуется архитектура mipsel (little-endian MIPS) — на другом роутере
  нужно поменять путь к бинарнику в `setup.sh` под свою архитектуру.
- YouTube-приложение на LG WebOS пока не до конца работает (чёрный экран
  после логотипа) — в процессе диагностики, возможно не хватает ещё
  каких-то доменов авторизации/API.
- Netflix через этот механизм не решается (блокировка по гео-IP, а не DPI) —
  для него планируется отдельная VPN-маршрутизация по доменам.
